# 🎓 University Module Timetable System

A Spring Boot application for managing university modules, convenors, and teaching sessions.

## 🚀 Features
- **Module Management**: Create/update modules with codes, titles, and levels  
- **Session Scheduling**: Track session topics, durations, and timestamps  
- **Convenor Assignment**: Assign professors/lecturers to modules  
- **Spring Data JPA**: Persistent storage with H2/MySQL database  

## 💻 Technologies
- Java 17  
- Spring Boot 3.x  
- Spring Data JPA  
- H2 Database (Dev) / MySQL (Prod)  
- Maven
